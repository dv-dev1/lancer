# lancer

## Intenção

1. Todo dia a coleta acha leads novos no Google Maps, aberto num navegador sem login (decisão D2: nada pago), por nicho × bairro de João Pessoa. Ela detecta as dores (sem site, site que é rede social ou agregador, site próprio ruim, reclamação nas avaliações) e filtra por porte. Quando o Maps esconde a contagem de avaliações, o porte usa só a nota. Cada lead entra na fila com mensagem pronta e variante A/B sorteada (texto ou link de preview). O custo sobe junto com o interesse: o LLM só roda para quem passou nos cortes baratos.
2. O painel mostra a fila do dia com o botão wa.me, o "cobrar hoje", a ficha do lead e a taxa de resposta por variante, nicho e dor, sempre com o `n` ao lado.
3. O funil anda sozinho. O whatsmeow só escuta o número pessoal e marca `contatado` e `respondeu`. A visita ao preview marca `abriu`, sem contar o robô que monta o card do link. Três dias depois do follow-up sem resposta, o lead vira `perdido`. Nenhuma conversa pessoal é gravada.
4. Cada lead tem um preview em `/p/<slug>`, montado a partir do template do nicho, com os dados reais e itens de exemplo marcados com selo. Tem card de link (`opengraph-image`) e não gasta token.
5. O repo é público, com README (mostrando saída real), LICENSE MIT e CI.

## Critério de aceite

Fase 1 — coleta no terminal:

```bash
cd ~/lancer && go vet ./... && go test ./...
# ok

set -a && source .env && set +a && go run ./cmd/coleta --nicho confeitaria --bairro "Manaíra" --limite 5
# até 5 leads, cada um com dores, nota (n), variante e mensagem; descartes por motivo; teto em US$
```

Fase 2 — banco e painel:

```bash
cd ~/lancer/web && npm test && npm run lint && npx tsc --noEmit && npm run build
# verde
cd ~/lancer && go run ./cmd/coleta --nicho confeitaria --bairro "Manaíra" --limite 5 && go run ./cmd/coleta --nicho confeitaria --bairro "Manaíra" --limite 5
# a segunda rodada não detalha de novo nenhum place_id da primeira (Detalhes = só os novos)
```

Fase 3 — escuta, preview e deploy:

```bash
cd ~/lancer && go test ./...
curl -s -o /dev/null -w '%{http_code}\n' "https://<app>.workers.dev/p/<slug>"
# 200
```

Ponta a ponta, feito à mão com um segundo número no papel de lead:

1. Enviar pelo wa.me do painel leva a etapa para `contatado`.
2. Responder leva para `respondeu`.
3. Abrir o preview registra a visita.
4. O card do WhatsApp não conta como visita.
